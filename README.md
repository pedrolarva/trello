# Kanban Board

Um aplicativo de quadro Kanban web simples, inspirado no Trello, desenvolvido com HTML, CSS e JavaScript puro.

## Funcionalidades

- **Quadros (Listas):** Crie, edite o título ou exclua listas.
- **Cartões:** Adicione, edite (título, descrição, cor) ou exclua cartões dentro das listas.
- **Arrastar e Soltar (Drag and Drop):** Mova cartões entre as diferentes listas de forma intuitiva.
- **Persistência de Dados:** Todos os seus dados (listas e cartões) são salvos no armazenamento local do navegador (localStorage), para que você não os perca ao recarregar a página.
- **Design Responsivo:** Interface amigável e scroll horizontal para acomodar várias listas.

## Como Executar

Não é necessário nenhum servidor ou configuração complexa. Basta abrir o arquivo `index.html` em qualquer navegador web moderno.

1. Baixe os arquivos (ou clone o repositório).
2. Dê um duplo clique em `index.html` ou arraste-o para o seu navegador.

## Tecnologias Utilizadas

- HTML5
- CSS3 (Flexbox, Variáveis, Scrollbars personalizadas)
- JavaScript Vanilla (Manipulação do DOM, Drag and Drop API, LocalStorage)
- FontAwesome (Ícones)
